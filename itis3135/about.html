About This Course Site

This page is built in part to demonstrate work for the Charlotte class ITIS 3135 - Front-End Web Application Development for sections taught by Mr. von Briesen. Additional information about the course is available on the ITIS 3135 course site.

This course seeks to provide students with relevant experience in front-end web application development by building multiple websites using a variety of tools and techniques.

Course Tools

The tools the course uses specifically include:

  • VS Code
  • Emmet within VS Code
  • SFTP via FileZilla
  • Git via GitHub Desktop and GitHub.com
  • Various browser tools
  • The Accumulus Validator

Course Websites

The sites students will build include the following. Links are provided for the sites currently available in my course portfolio.

  • A personal home portfolio
  • This course site
  • A design firm site representing a fictitious or aspirational design/consulting firm named after the student
  • A Crappy page, intended to do all the bad things so as to avoid them anywhere else
  • A whimsical product company
  • A student/colleague/peer management tool
  • A client project website
